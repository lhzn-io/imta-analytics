# References

Reference documents used by the analysis and by AI agents working in this repository. Full texts are converted from PDF with `make refs-md`; the PDFs themselves are never committed.

## Publication Policy

This repository is public, so a full text is committed only when its licence permits redistribution (Creative Commons or public domain). Everything else is kept locally: the converted markdown stays on disk for local and agent use, and `.gitignore` excludes `refs/publications/*.md` and `refs/technical/*.md` so new conversions are not published by accident. To publish a newly added open-access paper, confirm its licence and run `git add -f` on the file.

Citation metadata for all papers is in [publications/references.bib](publications/references.bib). Licences were checked against Crossref and the documents themselves on 2026-10-05.
