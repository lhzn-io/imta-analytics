# Research Publications and References

This directory contains references to research papers, articles, and other publications relevant to IMTA (Integrated Multi-Trophic Aquaculture) research.

## Organization

Publications are organized by topic and stored as BibTeX files or markdown documents with citations.

### Key Research Areas

#### 1. IMTA Fundamentals
- Core concepts and principles of integrated multi-trophic aquaculture
- Historical development and evolution of IMTA systems
- Ecological foundations and ecosystem services

#### 2. System Design and Implementation
- Design principles for IMTA systems
- Species selection and compatibility
- Spatial configuration and optimization
- Infrastructure and technology requirements

#### 3. Nutrient Dynamics
- Nitrogen cycling in IMTA systems
- Phosphorus dynamics and management
- Carbon flow and sequestration
- Bioremediation capabilities

#### 4. Production and Economics
- Economic viability and profitability studies
- Market analysis for IMTA products
- Comparative studies with conventional aquaculture
- Risk assessment frameworks

#### 5. Environmental Sustainability
- Environmental impact assessments
- Life cycle analysis (LCA) studies
- Sustainability indicators and metrics
- Climate change mitigation potential

#### 6. Case Studies
- Regional IMTA implementations
- Species-specific case studies
- Success stories and lessons learned
- Challenges and solutions

## File Formats

### BibTeX Files
Store references in `.bib` files for easy integration with LaTeX and reference managers:
- `imta_fundamentals.bib` - Core IMTA concepts
- `system_design.bib` - Design and implementation
- `nutrient_dynamics.bib` - Nutrient cycling studies
- `economics.bib` - Economic analyses
- `sustainability.bib` - Environmental studies
- `case_studies.bib` - Case studies and applications

### Markdown Summaries
Create markdown files summarizing key papers:
- Include citation information
- Brief abstract or summary
- Key findings and relevance
- Links to DOI or paper URL

Example format:
```markdown
## Paper Title
**Authors**: Author1, Author2
**Year**: 2023
**Journal**: Journal Name
**DOI**: 10.xxxx/xxxxx

### Summary
Brief summary of the paper...

### Key Findings
- Finding 1
- Finding 2

### Relevance to Our Research
How this paper relates to our work...
```

## Citation Management

### Using BibTeX
```bibtex
@article{author2023,
  title={Paper Title},
  author={Author, First and Author, Second},
  journal={Journal Name},
  volume={10},
  number={2},
  pages={123--145},
  year={2023},
  publisher={Publisher},
  doi={10.xxxx/xxxxx}
}
```

### Importing References
1. Export citations from your reference manager (Zotero, Mendeley, EndNote)
2. Save as BibTeX format
3. Add to the appropriate `.bib` file in this directory

## Best Practices

1. **Consistent Formatting**: Use consistent citation keys (e.g., `author_year_keyword`)
2. **Complete Metadata**: Include all available metadata (DOI, ISSN, URLs)
3. **Avoid Duplicates**: Check for existing entries before adding new ones
4. **Regular Updates**: Keep the reference list current with new publications
5. **Access Notes**: Note if papers are open access or require institutional access
